关于我

我是夏昕濛，南京大学计算机科学与技术系博士研究生，计算机软件新技术国家重点实验室成员，指导教师为徐宝文教授与冯洋教授。我的研究方向是程序分析与软件测试，关注如何在语言实现层面（解释器、编译器、运行时）系统性地发现缺陷。

具体而言，我的工作围绕三条线索展开：一是动态类型语言（尤其是 Python）的类型实践及其对软件维护性的影响；二是基于骨架程序枚举的解释器与编译器缺陷检测；三是面向并发程序的数据竞争检测。相关成果发表于 ACM TOSEM、IEEE ISSRE、IEEE QRS、IJSEKE 与《软件学报》。

目前我在华为仓颉编程语言实验室工作，参与仓颉编程语言的研发与开发者生态建设。

研究方向

解释器与编译器测试

基于骨架程序枚举（skeletal program enumeration）生成语义等价但结构不同的测试程序，用于系统性地暴露 Python 解释器与 Rust 编译器的实现缺陷。

动态类型语言的实证研究

分析真实 Python 项目中动态类型的使用模式、普及程度与风险实践，并量化其对变更倾向、维护耗时与提交接受率的影响。

并发缺陷与模糊测试

结合共享变量分析与约束求解检测安卓应用的数据竞争；面向 Python 库设计基于骨架结构的模糊测试方法。
